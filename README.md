# Soccer Training App

A youth soccer training app built from coach workout sheets.

## Design System

Master Reference Screen:

Square Cone Drills

This screen defines:

- Layout
- Colors
- Typography
- Navigation
- Screen Structure

All future drill screens must match this design language.

## Even Day Workout

1. Square Cone Drills
2. 10 Yard Drills
3. Ladder Drills
4. T Cone Drills
5. W Cone Drills
6. Plyometrics
